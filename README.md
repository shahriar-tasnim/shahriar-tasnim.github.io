# Shahriar Tasnim — GitHub Portfolio

A responsive engineering portfolio built with plain HTML, CSS, and JavaScript. It is ready for GitHub Pages and does not require a build system.

## Live site repository

For the clean portfolio address below, create a **public** repository named exactly:

```text
shahriar-tasnim.github.io
```

The published site address will be:

```text
https://shahriar-tasnim.github.io/
```

## Upload using the GitHub website

1. Sign in to GitHub and select **+ → New repository**.
2. Name the repository `shahriar-tasnim.github.io`.
3. Select **Public**, then create the repository.
4. Extract the downloaded ZIP on your computer.
5. Open the new repository, select **Add file → Upload files**.
6. Drag **all files and folders inside** `shahriar-github-portfolio-final` into the upload area. Do not upload only the ZIP file.
7. Enter a commit message such as `Publish portfolio website`, then select **Commit changes**.
8. Open **Settings → Pages**.
9. Under **Build and deployment**, choose **Deploy from a branch**.
10. Choose the `main` branch and `/ (root)` folder, then select **Save**.
11. After deployment completes, visit `https://shahriar-tasnim.github.io/`.

## Update the website later

Edit or replace files in the same repository and commit the changes. GitHub Pages will redeploy the site automatically from the selected branch.

## Local preview

From the project directory, run:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.
